# GameCurve - 游戏数据曲线编辑器

面向游戏策划的功能：打开任意 `.xlsx / .xlsm` 工作簿，选择某个工作表的一列（或多列）数值，将其可视化为曲线；曲线上的每个数据点对应一个 Excel 单元格，可直接拖动点位、框选、多选、全选并通过键盘微调，改动会自动写回 Excel；反之，在表格里手工改单元格，曲线上对应的点立即跟随变化。

## 运行

已发布自包含单文件程序（无需安装 .NET）：

```
GameCurve\publish\GameCurve.exe  [工作簿路径]
```

不传参数则启动后通过“打开”按钮选择文件；传路径会直接打开并自动定位到数据最丰富的数值列。

## 从源码构建

需要本机已安装 .NET 9 SDK + Windows 桌面运行时：

```
dotnet build -c Release
dotnet publish GameCurve.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

## 功能一览

- **工作簿读取**：支持 `.xlsx` / `.xlsm`，自动识别表头行（按字段定义标记，如 `: < .json`），自动识别数值列（按 `<long>/<int>/<double>` 等类型注解，或按数据占比推断），识别 `json / 数组 / 布尔 / 文本` 列并跳过。
- **工作表切换**：仿 Excel 在窗口底部放置工作表标签页，点击即切换；打开时自动定位到数据最丰富的数值列。
- **多曲线叠加**：勾选多个数值列同时显示，可比较不同列走势；用“编辑列”选择当前可编辑列。
- **X 轴**：默认使用物理行号，也可选某一数值列作为 X（此时拖动可横移 X 的单元格值）。
- **点交互**：
  - 单击选点、`Ctrl+单击` 多选切换、空白处拖拽框选、`Ctrl+拖框` 追加选择、`Ctrl+A` 全选、`Esc` 取消。
  - 拖拽选中点移动，多选时整体平移；`↑↓←→` 微调（`Shift` ×10、`Ctrl` ×0.1），步长可在右侧设置。
  - 双击图表或“自动适配视图”恢复视野；滚轮缩放，右键/中键拖拽平移。
- **Excel 双向同步**：拖点/按键/批量操作结束后自动写回对应单元格（可选“自动保存”开关，另提供“保存”）；下方表格**任意单元格都可直接编辑**：改数值列会**实时更新对应的曲线**，若是当前编辑列还会进入撤销/未保存记录；外部用 Excel 编辑并保存时，程序监视文件变动并自动重载曲线。
- **表格与曲线联动**：点一下表格某单元格，就自动选中曲线上对应的那个点（所在列为曲线则会切为该曲线的编辑列）。
- **空单元格**：点空白单元格再失焦不会有提示、也不会自动填 0，保持原样。
- **切换保护**：切换工作表（或关闭程序）前，若有未保存改动会弹出提示，可选“保存 / 不保存 / 取消”，避免切表或退出时丢失数据。
- **记住文件**：上次打开的 Excel 文件路径会保存，下次启动自动打开并最大化。
- **批量操作**：设置数值、整体偏移、缩放、钳制上下限、整列平滑、归一化、随机扰动。
- **统计**：当前列的 数量 / 最小 / 最大 / 平均 / 中位 / 总和 / 标准差。
- **右键菜单**：右键点击某条曲线可“设为当前编辑列 / 隐藏 / 仅显示 / 显示全部 / 整列平滑 / 归一化”；右键空白处可“自动适配视图 / 显示开关（平滑、网格、数据点、坐标标签）/ 导出 PNG / 刷新 / 打开”。
- **布局**：左侧为“列选择面板”，最右侧为“编辑/批量/统计功能面板”（宽度容纳全部组件）；中间为曲线区 + 数据表格，两者之间的分隔条可拖动调整高度/宽度；工具栏“布局”可切换“表格置底 / 表格靠右”，让表格与曲线左右并列显示，并且工作表标签始终紧贴表格底部、随表格一起移动。程序启动即最大化，并记住面板宽度、分隔条位置、表格方向等布局（保存在 `%APPDATA%\GameCurve\layout.json`）。
- **撤销/重做**：每次编辑结束（拖点、按键、批量、改表格）都会记录一步，`Ctrl+Z / Ctrl+Y` 或工具栏按钮即可撤销/重做（与是否自动保存无关）。
- **批量操作**：点击左侧“曲线列”时勾选要显示的列；对当前编辑列的“设为值 / 偏移 / 缩放 / 钳制 / 整列平滑 / 整列归一化 / 随机扰动”等批量操作集中在右键菜单“批量操作”子菜单中，需要数值时会弹出输入框。
- **悬浮提示**：界面每个控件（含右键菜单项）均有功能说明。
- **其它**：撤销/重做（`Ctrl+Z / Ctrl+Y`）、导出曲线为 PNG、另存为新文件、标题栏显示未保存状态；默认关闭“自动保存”，改动需点“保存”才写回 Excel。
- **安全写回**：只修改被编辑的单元格，完整保留原工作簿的格式、公式、共享字符串与 `宏（vbaProject.bin）`。

## 说明

- Excel 文件正被 Excel 打开并独占锁定时，工具可能无法写入，届时状态栏会提示“文件被占用，请关闭 Excel 后重试”。
- 大表（数千行）曲线会自动降级为“直接连线”以保持流畅。
- 文件处理基于 DocumentFormat.OpenXml。
